An exploratory comparison of how selected public-examination notices become claims in secondary reporting.

RoleSource selection · Claim coding · Audit writing

Evidence status: Working report with selected cases; no independent human adjudication, publication or population-rate inference.
Read the public research report ↗

The question
behind the work.

In institutional reporting, a corrected number is not always a corrected outcome. A process announced is not always a process completed. This project studies those distinctions in specific Indian examination records.

Corpus and method

The public working report uses a purposively selected 12-item diagnostic comparison and a separate 10-slot retrospective lookup grid. These are distinct collections and are not pooled into a prevalence estimate.

Cases include an SSC corrigendum, NEET-UG fee-refund notice stages and a CUET-UG rescheduling announcement. Each statement is checked against the object, time and administrative stage in its cited primary source.

Interpretation codebook

Direct contradictionThe named official source explicitly rules out the secondary claim.
Unsupported completionA report asserts a completed outcome that its identified source documents only at an earlier stage.
AlignedThe report correctly preserves source, object, scope and process stage.
UncertainThe record cannot support a defensible classification; uncertainty is retained.

Boundaries

The study is not a representative media audit and does not establish error rates, motives, audience effects, or factual truth of events not independently verified. The code checks corpus structure and declared distributions; it does not prove that judgments are correct.

This work demonstrates documentary discipline rather than statistical generality.

A source can establish a procedural step without proving the intended result occurred.
