Reinforcement learning · Active probing · Causal ambiguity

Reality Attribution.

Can an agent discriminate genuine world change from stale observations or hidden intervention using active, evidence-seeking probes?

Why this
project exists.

An agent may observe an unexpected transition because the world changed, its observation is stale, or an external actor intervened. Passive prediction error can flag that something is wrong, but it may not identify which reality generated the error.

The attribution gap

Environmental change, observation lag and hidden intervention can produce overlapping transition residuals. A detector can therefore look accurate while still confusing the underlying cause.

The research question became: can carefully selected actions generate discriminative evidence that passive observation cannot?

Experimental design

Two environmentsGlitchGrid provides controlled causal structure; LunarLander tests whether the logic survives continuous state and more complex dynamics.
Three perturbation classesEnvironmental control changes, memory or observation lag, and hidden external interventions are evaluated separately.
Active probesThe agent executes short diagnostic action sequences after a trigger, trading probe cost against conditional attribution accuracy.
Multi-seed evidenceAblations, temporal metrics, trigger rates, class-wise performance and uncertainty analysis guard against single-run stories.

What the project contributes

The core contribution is the framing of active probing as an attribution problem rather than only anomaly detection. The pipeline records passive errors, probe responses and temporal outcomes in a reproducible experiment structure.

The scientific boundary is equally important: successful attribution in chosen environments would not prove general causal identification. Probe design, distribution shift and intervention overlap remain open limitations.

Detecting surprise is easier than explaining surprise. The project is built around that difference.

Latest evidence snapshot

The November 2026 source/evidence audit reproduced every manuscript GridWorld Table 2 count from the staged aggregation file. It also recorded 50 passing GridWorld tests after restoring separately identified supporting assets.

This is bounded artifact verification—not a fresh re-execution of all simulator comparisons or a release reproducibility certificate. A LunarLander source-version discrepancy and missing definitive experimental results remain open.

Completed: finite-domain verification. Uncompleted: publication-level LunarLander confirmation.
